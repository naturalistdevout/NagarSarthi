# NagarSarthi — Jaipur Demo

A front-end prototype of the NagarSarthi civic complaint platform.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new GitHub repository, e.g. `NagarSarthi`.
2. Upload `index.html` (and this README).
3. Open the repository's Settings → Pages.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide your public Pages URL.

## Included demo features
- Jaipur / Ward 67 location
- Citizen dashboard
- Complaint reporting
- Issue categories
- Nearby issues and upvotes
- Complaint list
- Municipality information
- Dark mode
- Responsive glassmorphism UI
- Demo Aadhaar/e-KYC verified status

For a production system, connect authentication, database, maps, notifications, municipal APIs and an authorized e-KYC provider. Do not store raw Aadhaar numbers unnecessarily.
